Case study · AI concept

Trustline

An AI-guided verification assistant that explains what a banking security field is and where to find it, built to fix a specific drop-off an earlier login-flow audit uncovered.

TypePersonal exploration, extending an independent audit
FocusAI behavior design, trust
ToolsFigma, HTML / JS prototyping

FIG 1 · The assistant catching a wrong-format User ID the moment it's submitted

01

Where it came from

The UBA OTP audit already flagged this: a User ID requested with no context, discovered only after the flow fails. Trustline is my answer, not another help article, but something that meets people at whatever's actually confusing them. Fictional bank name, original concept.

02

The problem

A User ID isn't an account number, but nothing in a user's mental model of “my bank” says so. People type what they have and bail when none of it works.

03

Proof this isn’t a one-off

40–60%
of prospective customers lost during onboarding, across African digital banks, before a single transaction
1 in 5
financial applications abandoned specifically over identity-check friction
30–50%
cut in abandonment where AI-guided onboarding replaces static forms

Source: Youverify

04

How it solves it

User ID confused with account number
→
instant correction, the moment a wrong-format value is submitted
No help until something visibly fails
→
a nudge after 15 seconds with no attempt at all
A static FAQ can't adapt to what's actually confusing someone
→
two guided suggestions, then a handoff to a person
An AI that could leak account details if asked the wrong way
→
scoped to generic guidance only, never a specific value
